Privacy Policy

This policy covers Sermon Clips Uploader ("the tool"), a private tool operated by Benjamin Fiadonu.

YouTube API Services

The tool uses the YouTube API Services. By using it, you agree to the YouTube Terms of Service, and your data is also handled under the Google Privacy Policy.

What the tool accesses

When the channel owner signs in with Google, the tool receives permission to upload videos to, and manage videos on, the YouTube channels that account owns. It uses that permission only to upload video files, set titles, descriptions, thumbnails and visibility, and read back the status of the videos it uploaded.

What the tool stores

The only data stored is the Google sign-in token, kept on the owner's own computer so he does not have to sign in each time. The tool has no server and no database. It does not collect, store, sell or share any information about YouTube viewers or any other person, and it does not use cookies or analytics.

Data retention and deletion

The tool keeps no YouTube data. Video status it reads is shown once on screen and not saved. The only stored item is the owner's OAuth token on his own computer; it is deleted when access is revoked (see below) or when the owner removes the tool. If any data obtained from the YouTube API Services were ever stored, it would be deleted within 30 days, as the YouTube API Services Developer Policies require.

Sharing

No data obtained through the YouTube API Services is shared with any third party.

Revoking access

Access can be revoked at any time from the Google security settings page at myaccount.google.com/permissions. Deleting the stored token from the owner's computer also ends the tool's access. To ask about any data, email the contact address below; requests are answered within 7 days.

Changes

Any change to this policy will be posted on this page with a new date.
